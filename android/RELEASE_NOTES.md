Version 1.0.4 — REC Remote Pad. Fixed landscape button-only interface: forward/reverse/left/right and center stop on the left; left clamp open/close and right clamp open/close on the right; a Bluetooth connection button at the top. No joystick, overflow menu, timer, speed panel or terminal button on the main screen. Uses a distinct application ID com.shenen.rec.pad.debug to avoid the existing REC Remote package/signature conflict. Launch the newly installed app named REC Remote Pad. Existing corrected drive/right clamp directions are retained.

Download RECRemote-Pad-v1.0.4.apk. Android 8+. This is a signed development APK; real robot behavior still needs physical testing.
